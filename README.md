# 39 ChemAI: Predict the Cure - найти наиболее эффективную комбинацию параметров для разработки лекарства
 Команда фармацевтической разработки ML и Data-инженеров должна построить модели, способные предсказывать эффективность новых соединений при разработке новых лекарственных препаратов на основе данных о свойствах молекул и их биологической активности против вируса гриппа.

В соревновании используются данные о 1000 химических соединениях, описанных с помощью числовых молекулярных дескрипторов.
Каждое химическое соединение описывается 214 числовыми признаками, отражающими его физико-химические, структурные и электронные свойства.

Можно обучать:
одну многоцелевую модель
или отдельные модели для каждой переменной

Решение
Для каждого химического соединения необходимо создать pipline решения и предсказать три показателя:
IC50 (mM) — концентрация, при которой вещество подавляет 50% активности вируса
CC50 (mM) — концентрация, при которой вещество токсично для 50% клеток
SI (Selectivity Index) — индекс селективности.

Оценка

Задача оценивается по метрике RMSE (Root Mean Squared Error), усреднённой по трём таргетам:

score = (RMSE(IC50) + RMSE(CC50) + RMSE(SI)) / 3
