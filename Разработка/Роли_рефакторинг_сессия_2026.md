# Роли команды: рефакторинг сессионного проекта ChemAI

**Контекст:** переделка работы после замечания преподавателей (злоупотребление нейросетями / «нечеловеческий» вид).  
**Финальный артефакт сдачи:** один файл `notebooks/avo_chemai_predict_the_cure.ipynb`.  
**Эталон процесса:** проект sygnal_types (`1_Инструкция_агент_единый_ipynb.md`, `1_Отчёт_единый_ipynb.md`).

---

## Принцип работы

1. **Разработка** — в репозитории (`ml/src/chemai/`, скрипты, черновые ячейки).
2. **Сборка сдачи** — генератор `scripts/build_avo_chemai.py` + тексты выводов `scripts/notebook_conclusions.py`.
3. **Проверка** — Run All ноутбука; цифры в markdown совпадают с output ячеек.
4. **Голос текста** — от лица студента, простой язык, без «AI-шаблонов».

## Правила для всей команды

1. **Один ноутбук = один Run All**, без `from chemai import ...`.
2. **Цифры только из ячеек** — после правки текста перезапустить Run All.
3. **Показать 1 неудачный эксперимент** (ICA или PCA-only) — это нормально для студента.
4. **Run All → submission2_a4** (LB 349.31) через `tools/author4 --only 2` — тот же путь, что использовался на Kaggle.
5. **Коммиты** — по одному § или одной роли; сообщения короткие, по-русски.
