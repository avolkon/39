## 2. Findings

### High

#### H-1. Небезопасная десериализация `joblib.load`

**Файлы:** `ml/src/chemai/predict.py`, `ml/src/chemai/preprocessing/preprocessor.py`

`joblib.load(path)` использует pickle → при подмене `.joblib` возможно RCE (CWE-502).

**Сценарий:** компрометация каталога `ml/models_saved/` между `--train` и `--predict`.

**Remediation:** SHA-256 sidecar в `metrics.json`; проверка перед load; права только для владельца; не загружать чужие артефакты.

---

#### H-2. Произвольные пути из конфигурации

**Файлы:** `ml/src/chemai/utils/config.py`, `predict.py`, `train.py`, `run_pipeline.py` (`--config`)

`CHEM_DATA_DIR`, `CHEM_MODELS_DIR`, `CHEM_SUBMISSIONS_DIR` принимают любой `Path` без sandbox относительно корня репо.

**Remediation:** валидатор «путь внутри repo root»; документировать доверие к `.env`.

## 3. Positive controls (уже реализованы)

- **Нет** `eval`/`exec`/`subprocess`/`os.system` в `ml/src/chemai/`
- **Нет** сетевых вызовов в production ML-коде
- `.env` в `.gitignore`; `.env.example` без секретов
- Pydantic `extra="ignore"` — лишние env не попадают в Config
- Фиксированные имена CSV (`train.csv`, `test.csv`)
- Per-fold `Preprocessor` — anti-leakage
- `postprocess`: clip IC50/CC50 > 0, SI ≥ 0
- Данные/модели/сабмиты в `.gitignore`
- `uv.lock` с SHA-256 wheels
- Smoke-тест train→predict (`tests/test_pipeline_smoke.py`)
- Ruff lint в `pyproject.toml`
- Единый entrypoint `run_pipeline.py` (каталог `tools/` удалён)

---

## 4. Рекомендации для сдачи

1. **Не коммитить:** `.env`, `*.csv` данных, `*.joblib`, локальные submission.
2. **Reproducibility:** `uv sync --locked` или `pip install -e ".[dev]"`; `CHEM_RANDOM_SEED=42`.
3. **Цепочка доверия:** `--train` → `--predict` на одной машине; не копировать чужие модели.
4. **README:** явно указать офлайн-характер, отсутствие секретов, риск pickle.
5. **Submission:** колонки `index, IC50, CC50, SI`; без Excel-формул.
