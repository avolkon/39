

Ниже - **детализированный pipeline решения** именно в том разрезе, как он будет применяться **к каждому химическому соединению** из тестовой выборки (и к каждому объекту обучающей – для кросс-валидации). Пайплайн построен с учётом моих предыдущих рекомендаций (и исправлений, которые внёс химик-нобелевский лауреат).

---

## Pipeline решения для одного химического соединения (в production-стиле)

**Вход:**  
- Вектор `X` – 214 числовых молекулярных дескрипторов для одного соединения (строка из `test.csv` без индекса).

**Выход:**  
- Три числа: `(IC50_pred, CC50_pred, SI_pred)`.

### Шаг 1. Предобработка на уровне объекта (применение обученных трансформеров)
- Если на этапе обучения были удалены признаки с высокой долей пропусков (>30%) или нулевой дисперсией – удалить эти же признаки из `X`.
- Если были добавлены **химические признаки** (например, `MolLogP / TPSA`, отношение ароматических колец к HeavyAtomCount) – вычислить их для текущего соединения по исходным 214 дескрипторам.  
  *Примечание:* эти новые признаки создаются **внутри пайплайна**, а не только на трейне.
- Применить **стандартизацию** (например, `StandardScaler`), обученную на обучающей выборке:  
  `X_scaled = (X - mean_train) / std_train` (только для признаков, которые масштабировались).

### Шаг 2. Предсказание трёх таргетов (ансамбль из моделей)
Каждый таргет предсказывается **независимо**, без использования связей между ними (так как в данных `SI` ≠ `CC50/IC50`).

#### Для `IC50`:
- Модель A: `LightGBM` (обучен на `log1p(IC50)`)  
- Модель B: `XGBoost` (обучен на `log1p(IC50)`)  
- Модель C: `Ridge` (обучен на `log1p(IC50)`) – даёт устойчивость к выбросам  
- Модель D: **Нейросеть** (многозадачная, но для `IC50` берём предсказание из соответствующей головы)

**Агрегация:**  
`log_IC50_ensemble = (pred_A + pred_B + pred_C + pred_D) / 4`  
`IC50_pred = expm1(log_IC50_ensemble)`  (обратное преобразование)

#### Для `CC50`:
– Аналогичный ансамбль из тех же типов моделей, но обученных на `log1p(CC50)`.

#### Для `SI`:
– **Отдельный ансамбль** (те же модели, но целевая переменная – исходный `SI`, возможно, после `log1p`, если распределение сильно скошено).  
– **Важно:** никакого вычисления через `CC50_pred / IC50_pred` – это было бы ошибкой для данного датасета.

### Шаг 3. Постобработка (обеспечение физической и математической корректности)
- Если `IC50_pred < 0` → заменить на `1e-8` (минимальное положительное значение, соответствующее суб-наномолярному диапазону).
- Если `CC50_pred < 0` → заменить на `1e-8`.
- Если `SI_pred < 0` → заменить на `0` (индекс селективности не может быть отрицательным; `0` означает отсутствие селективности).
- (Опционально, если гистограмма предсказаний даёт выбросы > 10000 мМ – ограничить разумным максимумом, например, 10000).

### Шаг 4. Формирование выходной строки
- Записать `index` (из тестового файла), `IC50_pred`, `CC50_pred`, `SI_pred` в `sample_submission.csv`.

## Как этот pipeline вписывается в общий код (инфраструктура)

Для **обучения** (один раз до предсказаний):
1. Загрузить `train.csv` (750 строк, 214 дескрипторов + 3 таргета).
2. Создать дополнительные химические признаки (функция `add_chem_features`).
3. Обучить `StandardScaler` на всех признаках.
4. Обучить каждую из 12 моделей (3 таргета × 4 типа моделей) с кросс-валидацией.
5. Сохранить модели и трансформеры в файл (например, `pipeline.pkl`).

Для **предсказания** (на тесте):
1. Загрузить `test.csv` (250 строк).
2. Применить `add_chem_features`, затем `StandardScaler`, затем каждую модель.
3. Усреднить, постобработать, выдать CSV.

раткое описание основных файлов
run_pipeline.py – объединяет всё:

если флаг --train – обучает и сохраняет модели;

если флаг --predict – загружает модели и генерирует docs/submissions/final_submission.csv.

ml/src/chemai/features/build_features.py – функция, добавляющая 5–10 доменных признаков (например, 'LogP_TPSA', 'Arom_Heavy_Ratio', 'Charge_Sum', 'fr_imide_flag', 'fr_sulfone_flag').

ml/src/chemai/train.py и модули `ml/src/chemai/models/` – обучение кандидатов и ансамбль; опционально Optuna в `hyperopt.py`.

ml/src/chemai/validation/cv_splitter.py – реализует стратификацию по квантилям SI или кластеризацию по молекулярному весу/количеству колец.

requirements.txt – пример:

Инструкция по воспроизведению (для README.md)

1. Убедитесь, что `uv` установлен (см. инструкцию выше).
2. Клонируйте репозиторий и перейдите в папку проекта.
3. Создайте и активируйте виртуальное окружение:
   uv venv
   source .venv/bin/activate  # или .venv\Scripts\activate для Windows
4. Установите зависимости:
   uv pip install -r requirements.txt
5. Поместите `train.csv`, `test.csv`, `sample_submission.csv` в папку `ml/data/`.
6. Запустите обучение: `python run_pipeline.py --train`
7. Сделайте предсказание: `python run_pipeline.py --predict`
8. Результат: `docs/submissions/final_submission.csv`
