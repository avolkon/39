# Задание на разработку: Эпик 4 — Модели

## Контекст
Нужны три типа базовых моделей на каждый таргет с корректной шкалой для IC50/CC50.

## Файлы
`src/chemai/models/lgb_model.py`, `xgb_model.py`, `ridge_model.py`, `log_wrappers.py`, `neural_net.py`, `hyperopt.py`

## Задача
Обучение LGB/XGB с early stopping, RidgeCV; обёртка `Expm1Predictor` для log-целей; заглушки NN/Optuna.

## Критерии приемки
- [x] Модели обучаются на матрице признаков после preprocessor
- [x] SI не принудительно вычисляется из IC50/CC50

**Зависимости:** Эпик 3
