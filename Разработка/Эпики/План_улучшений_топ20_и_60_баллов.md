### 1.1. Текущее положение vs цель

| Показатель | Сейчас (команда 39) | Цель топ-20 | Цель топ-10 |

| Разрыв по метрике | — | **−83.9** (−24%) | **−86 – −91** |

Базовый воспроизводимый пайплайн (`train.py` → `final_submission.csv`) даёт порядка **~365** — ещё хуже. Stacking вне основного кода дал **~349**, но **не закрывает** половину пути к лидерам.

**Вывод:** инкрементальные правки (только stacking, только Optuna на LGB) **недостаточны**. Нужна **системная перестройка** постановки обучения, валидации и согласованности таргетов — при сохранении честности по регламенту Kaggle.

### 1.3. Гипотезы, почему топ-20 на ~84 пункта лучше

При одинаковых входных дескрипторах топ-команды, с высокой вероятностью, делают **не** «ещё один Ridge-stack», а следующее:

1. **Согласованное предсказание тройки (IC50, CC50, SI)** с учётом тождества `SI = CC50/IC50` на train и формулировки ТЗ («SI связан с IC50 и CC50»).
2. **Multitask / shared representation** — одна модель или связанные головы вместо трёх независимых ансамблей.
3. **Корректная работа с 121 дубликатом признаков (~16%)** — группы с **разными** таргетами = label noise; нужны robust loss и веса, а не наивный GroupKFold «в лоб».
4. **Covariate shift train→test** — взвешивание train или отбор стабильных признаков (сдвиг `fr_oxazole`, `RingCount`, `MolMR` и др. в EDA).
5. **Системный HPO** (LightGBM / XGBoost / CatBoost) + **seed-ensemble** (5–10 сидов) + **OOF stacking 2–3 уровня** с метрикой **`competition_score`**, а не per-target RMSE.
6. **Исправление методологических дыр CV** (R1/R2 из ML-ревью) — текущий OOF **оптимистичен**; веса ансамбля могут быть смещены.

## 2. Стратегические принципы

1. **Один канонический путь в репозитории** — лучший сабмит генерируется `run_pipeline.py --train` / `--predict`, без отдельного `tools/`.
2. **Оптимизация под scalar метрику соревнования** — \(\frac{1}{3}(\mathrm{RMSE}_{IC50}+\mathrm{RMSE}_{CC50}+\mathrm{RMSE}_{SI})\) на OOF при подборе весов, blend SI и meta-learner.
3. **SI как структурное ограничение, не как «ещё один таргет»** — отдельная голова + калибровка через \(\widehat{CC50}/\widehat{IC50}\) с весом на OOF (в прошлых экспериментах `w→1` мог быть артефактом слабого SI-head, а не доказательством бесполезности ratio).
4. **Честная CV без утечек** — KMeans только на train-фолде; фиксированный список колонок `full_pre`; группы дубликатов не пересекают train/val.
5. **Документировать каждый скачок** — таблица «гипотеза → OOF → public LB» для жюри и доп. баллов за обоснование.

### Фаза 3. Оригинальность и финальный push (5–7 дней)

**Цель:** топ-20 (≤ **265.38**) и доп. баллы за нестандартный подход.

| # | Идея | Суть | Оригинальность |
|---|------|------|----------------|
| 3.1 | **Physics-informed SI (PISI)** | После предсказания IC50/CC50 решать constrained refinement: минимизировать \(\|SI - CC50/IC50\|\) при малом отклонении от model-SI (Lagrange / 1-step projection) | Высокая для хакатона |
| 3.2 | **Duplicate-aware learning** | При обучении: вес sample = \(1/\sqrt{n_{dup(group)}}\); при inference — стандартный predict | Средняя |
| 3.3 | **Stacking L2 + L3** | L1: 9 моделей × 3 таргета; L2: Ridge per target; L3: scalar blend под `competition_score` | Средняя |
| 3.4 | **Covariate-shift calibration** | Isotonic / linear calibration OOF по «pseudo-test» из adversarial val | Средняя |
| 3.5 | **Multi-fold strategy ensemble** | Усреднить предсказания ClusterKFold + DuplicateGroupKFold + StratifiedQuantileKFold (только meta на OOF) | Средняя |
| 3.6 | **Target transformation search** | Сетка: log1p IC50/CC50; log1p SI; Yeo-Johnson — выбор по OOF scalar | Низкая |

## 5. Повышение оригинальности (критерий до 5 баллов)

Текущая оценка преподавателя: **~2.5/5** (стандартный QSPR-стек).

**Пакет «ChemAI-Constrained Multitarget» для защиты:**

1. **PISI-layer** — явная физико-химическая связь SI с активностью/токсичностью после ML-прогноза.
2. **Duplicate-aware robust learning** — ответ на аномалию «один вектор дескрипторов — разные IC50».
3. **Shift-aware training** — adversarial sample weights под covariate shift из EDA.
4. **Единая meta-цель** — оптимизация mean RMSE на OOF end-to-end, а не три независимых пайплайна.

Это не GNN и не «магия», но **исследовательски оформленный** ответ на структуру **именно этого** датасета — достаточно для **4/5** по оригинальности при успешном LB.

## 6. Риски и анти-паттерны

| Риск | Митигация |
|------|-----------|
| GroupKFold ухудшил LB (373 vs 349) | Не использовать «честность ради честности»; комбинировать group split **только** для OOF-оценки, финальный fit — на all train; или soft weights вместо жёсткого group CV |
| SI = ratio на test не выполняется | Blend с весом на OOF; не hard-code ratio |
| Переобучение Optuna на 751 строк | Nested CV; holdout 20% для final HPO; penalty за сложность |
| Нарушение регламента (external data) | Только train/test Kaggle; без SMILES из PubChem |
| LLM-штраф | Все решения с ablation и устным объяснением на защите |

## 10. Резюме для команды

Разрыв **349 → 265** — это не «подкрутить learning rate», а **смена постановки**: multitarget, SI-constraint, честная CV, shift-aware weights, системный HPO и seed-ensemble.
