# ИБ: риски и рекомендации

## Десериализация (`joblib.load` / `pickle`)

- **Риск:** загрузка `pipeline_bundle.joblib` и `preprocessor.joblib` выполняет произвольный код при подмене файла (RCE при компромиссе каталога `models_saved/`).
- **Меры:** хранить артефакты только из доверенной сборки; не подставлять файлы из недоверенных источников; ограничить права на каталог; при развёртывании — подписывать или хешировать артефакты.

## Пути к данным

- **Риск:** если путь к CSV когда-либо берётся из ввода пользователя без нормализации — обход каталога.
- **Текущий код:** пути из конфига (`CHEM_DATA_DIR` и т.д.); не передавайте в конфиг произвольные строки из внешних пользователей без валидации.

## Секреты

- Файл `.env` в `.gitignore`; используйте `.env.example` без секретов.

## Зависимости (supply chain)

- Регулярно обновляйте `pip`/`uv` и проверяйте уязвимости: например, `pip audit` или эквивалент в CI.
- Тяжёлые опциональные пакеты (`torch`) — только при необходимости.

## ML-специфика

- **Утечка таргета:** доменные признаки не используют `IC50/CC50/SI`; scaler fit только на train.
- **Недообучение / переобучение:** малый train (750) — честная CV обязательна; метрики в `metrics.json` не гарантируют результат на Kaggle-привате.

## Сетевые вызовы

- В ноутбуке `notebook_1.ipynb` есть `requests` для загрузки данных; **в production-пакете `chemai`** загрузка только из локальных CSV — сетевой вектор отсутствует.
