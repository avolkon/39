# Эпики и план реализации ChemAI: Predict the Cure

Источники: `ТЗ_Хакатон.txt`, `Архитектурная_концепция_Техдизайн.txt`, `pipeline.txt`, `Первичный_анализ.md`, Kaggle: `chem-ai-predict-the-cure`.

---

## Эпик 1. Инфраструктура и воспроизводимость

**Цель:** единый каркас репозитория, зависимости, конфиг, входные точки.

| Шаг | Действие | Детали | Артефакт |
|-----|----------|--------|----------|
| 1.1 | Окружение Python ≥ 3.11 | `pyproject.toml`, опционально `uv` / `pip install -e ".[dev]"` | editable install |
| 1.2 | Структура каталогов | `src/chemai/`, `tests/`, `data/`, `models_saved/`, `submissions/`, `notebooks/` | дерево проекта |
| 1.3 | Конфиг | `CHEM_*` через `.env` / `pydantic-settings`; файл `.env.example` | `src/chemai/utils/config.py` |
| 1.4 | CLI | `run_pipeline.py --train` / `--predict` | запуск без ноутбуков |
| 1.5 | Качество | `ruff check`, `pytest` в `Makefile` | CI-ready |

**Критерий готовности:** `uv run pytest` и `uv run ruff check` проходят; `make train` возможен при наличии `data/train.csv`.

---

## Эпик 2. Данные, признаки, предобработка

**Цель:** контракт загрузки, доменный feature engineering, масштабирование без утечки.

| Шаг | Действие | Детали |
|-----|----------|--------|
| 2.1 | Загрузчик | `load_train` / `load_test` / `load_sample_submission`, копии DataFrame |
| 2.2 | Химические признаки | `add_chem_features`: LogP/TPSA, arom/heavy, заряды, флаги fr_*, Ring×LogP |
| 2.3 | Preprocessor | медианы по train, выброс колонок с >30% NaN и нулевой дисперсией, `StandardScaler` |

**Инварианты:** таргеты не участвуют в признаках; `fit` только на train-части внутри CV или на полном train для финального артефакта (см. эпик 6).

---

## Эпик 3. Валидация

**Цель:** оценка обобщения с учётом химического разнообразия.

| Шаг | Действие | Детали |
|-----|----------|--------|
| 3.1 | `ClusterKFold` | KMeans по ключевым дескрипторам (MolLogP, RingCount, TPSA, HeavyAtomCount) или fallback на числовой срез |
| 3.2 | Метрика | RMSE по каждому таргету; отчёт средних по фолдам в `metrics.json` |

**Инвариант:** не использовать наивный случайный KFold без стратегии по структурам/кластерам.

---

## Эпик 4. Модели

**Цель:** три независимые цели (`IC50`, `CC50`, `SI`); для концентраций — обучение в `log1p`-пространстве.

| Шаг | Действие | Детали |
|-----|----------|--------|
| 4.1 | LightGBM | early stopping на holdout внутри train |
| 4.2 | XGBoost | аналогично |
| 4.3 | Ridge | `RidgeCV` как устойчивый baseline |
| 4.4 | (Опционально) NN / Optuna | заглушки `neural_net.py`, `hyperopt.py`; расширение при необходимости |

**Для SI:** без логарифма по умолчанию (`CHEM_LOG_TRANSFORM_IC50_CC50` влияет только на IC50/CC50).

---

## Эпик 5. Ансамбль и постобработка

**Цель:** смешивание моделей и физически корректный выход.

| Шаг | Действие | Детали |
|-----|----------|--------|
| 5.1 | Веса | обратно пропорционально средней RMSE по фолдам (с псевдодельтой 1e-8) |
| 5.2 | Ensemble | средневзвешенное предсказаний по lgb/xgb/ridge |
| 5.3 | Постобработка | `IC50, CC50 >= 1e-8`, `SI >= 0` |

---

## Эпик 6. Пайплайн обучения и инференса

**Цель:** один бандл артефактов и воспроизводимый submission.

| Шаг | Действие | Детали |
|-----|----------|--------|
| 6.1 | Train | честная CV с per-fold Preprocessor; финальные модели на `transform(полный train)` |
| 6.2 | Артефакты | `models_saved/preprocessor.joblib`, `pipeline_bundle.joblib`, `metrics.json` |
| 6.3 | Predict | идентичный `add_chem_features` + тот же preprocessor → ансамбль → `submissions/final_submission.csv` |

**Формат CSV:** `index,IC50,CC50,SI`.

---

## Эпик 7. Тесты, линтеры, документация

**Цель:** регрессии на уровне кода и понятный runbook.

| Шаг | Действие |
|-----|----------|
| 7.1 | `tests/`: признаки, preprocessor, постобработка, CV, сквозной smoke |
| 7.2 | `README.md`: установка, размещение CSV в `data/`, команды train/predict |
| 7.3 | Документы в `Разработка/Эпики` (эпики, задания, ИБ, принципы ревью) |

## Сводная метрика соревнования

`score = (RMSE(IC50) + RMSE(CC50) + RMSE(SI)) / 3` на скрытых тестовых метках (локально оцениваем только CV на train).
