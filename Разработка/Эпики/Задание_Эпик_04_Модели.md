# Задание на разработку: Эпик 4 — Модели

## Контекст
Для **каждого** таргета (`IC50`, `CC50`, `SI`) требуется **не менее девяти типов** моделей, наиболее подходящих для табличной регрессии на малой выборке; применимость по таргетам **проанализирована** в `Анализ_модельных_вариантов.md`, а **вклад** каждого типа **подбирается по CV** (разные веса для IC50 / CC50 / SI).

## Файлы
`src/chemai/models/candidate_models.py`, `lgb_model.py`, `xgb_model.py`, `ridge_model.py`, `log_wrappers.py`, `neural_net.py`, `hyperopt.py`

## Задача
Реестр из ≥9 кандидатов; обучение LGB/XGB с early stopping; линейные Ridge / ElasticNet / BayesianRidge; леса и sklearn-бустинги; опционально CatBoost; обёртка `Expm1Predictor` для log-целей IC50/CC50; заглушки NN/Optuna.

## Критерии приемки
- [x] Не менее 9 типов на каждый таргет (отдельные экземпляры и веса в бандле)
- [x] Документ с анализом по таргетам: `Анализ_модельных_вариантов.md`
- [x] SI не принудительно вычисляется из IC50/CC50

**Зависимости:** Эпик 3
